# FinalsTrack

FINALSTRACK – Exam Season Management System built with ASP.NET Core Web API, React, Bootstrap, and SQL Server (Lab Course 1).
Includes JWT authentication and role-based access (Student/Professor/Admin).

Students can view exam seasons and exams, track study time with study blocks, and log stress levels/notes using Stress Logs for each exam.
Professors can manage academic data: create/update/delete Subjects and Exams.
Admins can manage users, roles, and activate/deactivate accounts from the admin dashboard.

Project management and collaboration were done using Git (version control) and Trello (task tracking).
